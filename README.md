## Não é apenas um tradutor

Traduzir um jogo de RPG Maker não é simplesmente substituir palavras. Um comando alterado, uma quebra de linha ignorada, uma fonte incompatível ou o nome errado de uma imagem pode impedir o jogo de iniciar ou quebrar eventos durante a execução.

O LRPGM foi criado para resolver esse problema completo. Ele identifica o modelo e a estrutura do jogo, extrai os textos úteis, preserva elementos sensíveis, permite revisar o resultado e aplica a tradução com um fluxo pensado para manter o projeto jogável.

> **O benefício não é apenas traduzir. É traduzir com segurança.**

### Compatibilidade com projetos antigos e modernos

O LRPGM possui leitura e escrita próprias para formatos usados pelo **RPG Maker XP, VX e VX Ace**, sem exigir uma instalação externa do Ruby. Para **MV e MZ**, o programa entende a estrutura moderna do projeto, seus arquivos, plugins e padrões de controle.

Modelos atualmente contemplados:

- RPG Maker XP
- RPG Maker VX
- RPG Maker VX Ace
- RPG Maker MV
- RPG Maker MZ

> Jogos modificados, plugins de terceiros e estruturas personalizadas podem exigir ajustes específicos. O sistema de reports integrado ajuda a identificar esses casos e transformar correções reais em melhorias de compatibilidade.

## Um fluxo completo, do jogo à tradução

### 1. Adicione o jogo

Escolha a pasta do projeto. O LRPGM identifica automaticamente o modelo, a estrutura dos arquivos, os plugins ativos e o fluxo mais adequado.

### 2. Extraia somente o que importa

Selecione diálogos, eventos, banco de dados, plugins, scripts e outros recursos detectados. Os filtros reduzem ruído e protegem comandos que não devem ser tratados como texto comum.

### 3. Traduza com contexto

O programa identifica os idiomas encontrados, organiza o conteúdo e permite escolher o destino e o provedor de tradução mais adequado ao projeto.

### 4. Revise antes de aplicar

Corrija nomes, termos recorrentes e frases diretamente no fluxo de revisão. Você mantém o controle do resultado antes de qualquer alteração no jogo.

### 5. Aplique de forma reversível

No fluxo principal, o LRPGM adiciona um plugin leve e um arquivo separado com a tradução. Os arquivos originais permanecem preservados e, ao desativar o plugin, o jogo pode retornar ao estado anterior.

## Proteções que evitam jogos quebrados

- Preservação de comandos, variáveis, scripts e padrões de plugins.
- Detecção de códigos de controle usados nas mensagens do RPG Maker.
- Reconhecimento de quebras de linha padrão e personalizadas.
- Substituição de fontes incompatíveis quando necessário.
- Proteção de valores técnicos que não devem entrar na tradução.
- Correção de referências para imagens e arquivos quando nomes traduzidos causariam incompatibilidade.
- Perfis de compatibilidade e correções reutilizáveis para reduzir a repetição de falhas já identificadas.
- Relatórios técnicos enviados pelo próprio aplicativo, com o contexto necessário para investigar o jogo.

## Perguntas frequentes

## English overview

**Translate RPG Maker games without installing Ruby, without replacing original game files, and without breaking the game.**

LRPGM is a Windows translation workflow for RPG Maker XP, VX, VX Ace, MV, and MZ. It detects the game structure, extracts useful text, protects control codes and sensitive patterns, supports review, and applies translations through a reversible plugin-based workflow.

- Native handling for legacy RPG Maker formats without an external Ruby installation.
- Smart extraction and protection for commands, variables, scripts, and plugin patterns.
- Review tools before applying the translation.
- Separate translation files that preserve the original game data.
- Integrated reporting for modified games and compatibility issues.
